✦ HOW TO PUBLISH YOUR POST
  1. Write your post in the editor above, fill in the title, category, excerpt, and body.
  2. Click "⬇ Download .md File" — a file like 2025-05-27-your-title.md will download to your computer.
  3. Click "⬇ Download posts-index.json" — this updated list file will download.
  4. Go to your GitHub repo → _posts/ folder → drag and drop the .md file → commit.
  5. Also upload the posts-index.json to the root of your repo (replacing the old one) → commit.
  6. Netlify auto-deploys in about 30 seconds → your post is live! 🎉
